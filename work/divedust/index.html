Divedust

A 3D action game built around a card system, in a glassy Frutiger Aero world.

Type
Freelance project
Engine

Status

Three modes around the same playable character: an action mode for traversal and real-time combat, a turn-based card battle with a deck, and free exploration across the studio’s maps.

What I built

The player controller shared by the three modes: sprint, slide, wall run, wall jump, vault, ledge hang, parry, and a dodge with a perfect-dodge window, hit-stop and slow motion. Every value is set in metres and seconds, and the scripts check their own setup in the editor, so the level designer tunes movement without touching code.

A combat arena on top of it: enemies driven by a state machine pick telegraphed attacks from move sets authored as resources, and the threatened area fills up on the ground during the wind-up. Cards, dialogues, enemies and decks are resources too, edited through a set of in-house content editors.
